# Partner Workspace Template

Use this structure for each partner as integration work expands.

## Standard Layout

- `00-sources/`: source PDFs/links exported content
- `10-plan/`: digest, runbook, phased plans
- `20-environment/`: local/env setup status
- `30-operations/`: scripts and command recipes
- `40-evidence/`: logs, screenshots, proof artifacts
- `90-archive/`: raw captures and historical snapshots

## Recommended Minimum Files

- `README.md` (entrypoint)
- `10-plan/DIGEST.md`
- `10-plan/RUNBOOK.md`
- `20-environment/local/PHASE1.md`
- `30-operations/scripts/` helper scripts
- `40-evidence/logs/` with timestamped outputs
